# 五次课教师使用指引

版本：2026-11-13。每次135分钟，全部用于讲授、推演、练习。课程不另设正式考试，不改变正式教学文件中的成绩政策。

## 课堂节奏

每讲建议：15分钟回顾与问题，30分钟概念，35分钟机制推演，30分钟扩展，20分钟练习，5分钟总结。章节页用于确认位置，附录在提问或复习时查阅。

## 读图与绘图

先说明图种、节点与箭头含义，再沿数据或消息顺序读图。UML类图表达对象结构，活动图表达单条记录处理，组件图表达职责，部署图表达运行位置，状态机表达业务生命周期，时序图表达交互先后。DAG、双时间轴和屏障图各自使用明确的坐标与标签。

推演时先展示输入及条件，让学生预测下一步，再翻页核对。窗口专项严格先处理当前事件，再发水位线并执行计时器；故障专项先恢复状态，再从配套位置重放。

## 页面与讲稿

页面承载关键定义、机制、数据和步骤。讲稿补充读图顺序、提问、常见错误和衔接。可以在开发服务的演示者视图查看逐页讲稿；生产版未设置演示者口令时隐藏入口。

## 第5讲讲授安排

第5讲为54页，正文51页，附录3页。第1至4讲已按同一图解、推演和讲稿标准重构。

| 时间 | 页面 | 讲授与活动 |
| --- | --- | --- |
| 15分钟 | 1—6 | 订单案例回顾；日志、内存、持久数据与恢复点 |
| 30分钟 | 7—13 | 一致性切面、在途消息与配套输入位置 |
| 35分钟 | 14—27 | 连续屏障图、后台保存、时序图练习与非对齐恢复 |
| 30分钟 | 28—46 | 故障现场、漏计与重复、幂等及事务、方案示范 |
| 20分钟 | 47—50 | 独立方案设计与故障差额练习 |
| 5分钟 | 51 | 按输入、内部、出口复述完整恢复过程 |

讲稿采用课堂口述形式：先指图定位，再提问，沿记录解释原因，最后核对结果。屏障连续页始终使用同一通道位置：右侧旧记录先到算子；灰色已处理；红线是屏障；绿色是持久快照。红叉表示错误方案中被漏读的记录。

审阅时可先看第16—21页屏障过程、第29—37页内外恢复对照，以及第39—50页方案设计。开发服务的 `/presenter/` 提供逐页讲稿。

## 理论与实现

Dataflow组织What/Where/When/How；Flink的窗口分配、Trigger、聚合状态和Sink协议共同实现相应行为。勿把累积模式当成Flink通用同名开关，也勿把非对齐检查点与至少一次模式等同。Flink实现依据release-2.3文档；原教材参考章节可能使用旧术语和API，应以新五讲为本课程主线。

每讲先指明图种，再让学生沿箭头复述一条具体输入。对连续页保持对象位置稳定，先预测下一次变化，再翻页核对。讲稿可直接口述，关键条件与结果均在放映页。

第1讲先分清投递位置和业务身份，解释多出的2000分来自第二次E03；第2讲同时数10个算子子任务、8个Task和4个共享Slot，随后用500条/s的速度差定位积压；第3讲同时指当前事件、窗口状态和水位线，解释E进入第二窗为何触发第一窗；第4讲把业务有效范围、在线状态和到达先后分开，解释结束后支付为何进入补核。

方案设计均包含条件、计算规则、输出与验收数据。教师走读时隐藏讲稿，检查是否能仅凭页面完成输入追踪和因果解释；独立练习的答案另页提供。
